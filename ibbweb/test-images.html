Instructions for Gallery Page

  1. Open the Gallery page in your browser
  2. Open Developer Console (F12 or Right-click → Inspect)
  3. Go to the Console tab
  4. Look for these messages:
    • "API not available, using mock data"
    • "Mock data response:"
    • "Media items loaded: 12"
    • "First media item:"
    • "First media URL:"
  5. Check what URL is being generated
  6. Go to the Network tab
  7. Refresh the page
  8. Look for image requests (filter by "Img")
  9. Check if images are returning 404 or 200 status

Common Issues

  • Images showing as broken: URL paths are incorrect
  • Images loaded but invisible: CSS issue (opacity, z-index, color)
  • 404 errors: Files not found at the specified path
  • CORS errors: Cross-origin request blocked
